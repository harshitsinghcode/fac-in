Generates an interactive HTML satellite map with embedded 360° Mapillary viewers using 2D building footprints.

## 🔩 setup

Clone OpenFACADES into your current folder and install dependencies:

```bash
git clone https://github.com/seshing/OpenFACADES.git
pip install pandas geopandas shapely folium pydeck datasets
```
## 🪴usage

+ Run the generator script:
```
python mapi.py
```
View Map: Open the resulting .html file (e.g., street_view_satellite.html) in any web browser and click the markers to explore!
